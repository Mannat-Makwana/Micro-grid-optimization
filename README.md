Microgrid Energy Mix Optimizer for Off-Grid Communities

A smart energy management system designed to optimize electricity generation and storage for off-grid communities. The system combines solar, wind, battery storage, and diesel generation to meet demand reliably while minimizing operating costs, diesel dependency, and CO₂ emissions.

The platform uses 24-hour demand and renewable-energy forecasting followed by a MILP-based optimization engine to generate an efficient dispatch plan. A professional energy-management dashboard provides real-time system status, forecasts, battery state, optimized dispatch, alerts, and explainable recommendations.

Key Features

* 24-hour electricity demand, solar, and wind forecasting
* MILP-based energy dispatch optimization
* Solar, wind, battery, and diesel resource management
* Battery SOC and reserve management
* Cost and CO₂-aware optimization
* Rolling-horizon dispatch planning
* Explainable optimization recommendations
* Real-time-style microgrid monitoring dashboard
* FastAPI backend with REST APIs
* Responsive Vanilla JavaScript frontend

Technology Stack

Frontend: HTML5, CSS3, Vanilla JavaScript
Backend: Python, FastAPI
Forecasting: Machine Learning
Optimization: Mixed-Integer Linear Programming (MILP)

Project Status: HackOut’26 prototype. The current system is being developed with simulated data, with real forecasting models, optimization, and microgrid data integration planned as subsequent components.
